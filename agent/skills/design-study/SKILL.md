# 设计研究

目标：给出**能被审稿人和合作者直接评审**的方法学方案。

## 流程

1. `project_read` 确认研究问题；若项目没有明确问题，先用 `frame-question` 的思路收敛一个，再继续。
2. `library_search` 找 2-4 篇同类研究，提取它们的样本量、终点与统计方法作为参照。
3. 方案必须包含：
   - 研究类型与理由（观察性 / 干预性 / 回顾性 / 建模研究等）；
   - 研究对象、纳排标准、样本量估算依据；
   - 分组与对照（含阴性/阳性对照、盲法与随机化，如适用）；
   - 主要终点与次要终点（可测、有时间窗）；
   - 统计方法（效应量、检验、混杂调整、缺失值处理、多重比较）；
   - 偏倚控制与敏感性分析；
   - 伦理与数据合规要点。
4. 单独列「可行性风险」：数据可及性、样本招募、算力/实验条件、时间线依赖。
5. 用 `project_write` 存成产物「研究方案 - 主题」。

## 约束

- 不要给通用模板；每个小节都要落到当前问题。
- 样本量与统计方法要给依据，不要只写“待定”。
- 区分「必须做」和「有条件再做」，避免方案不可执行。
