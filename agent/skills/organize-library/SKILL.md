# 整理文献

目标：把文献库变成**可导航的主题结构**，并留下可复查的整理记录。

## 流程

1. `project_read`：了解当前项目主题与已有产物。
2. `library_tag`（不带 paperId）列出文献与现有标签，记录每篇的 paperId、标题、作者、页数。
3. 去重：按规范化标题（小写、去标点、去副标题）和作者+年份比对，找出疑似重复。
4. 聚类：按研究主题分组，每组给一个短标签（2-6 字），再给每篇 1-3 个标签。
5. `library_tag` 逐篇写入标签。默认 `mode=append`，只有在用户明确要求重置时才用 `replace`。
6. 用 `project_write` 保存整理报告：重复项、主题分组、每组代表论文、仍缺文献的方向。

## 约束

- 工具没有删除或合并论文的能力：重复项只能标注并建议人工处理，不要说“已合并”。
- 标签要复用已有标签，避免同义标签泛滥（如“免疫治疗”和“免疫疗法”只留一个）。
- 每篇最多 3 个标签；不确定的宁可不打。
- 报告里所有论文都要带 paperId，方便用户回查。
