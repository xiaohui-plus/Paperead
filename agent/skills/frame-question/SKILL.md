# 定研究问题

目标：产出 3 个**可验证、可落地**的问题，并推荐一个先做。

## 流程

1. `project_read`：读研究问题、项目描述与已有文件。
2. `library_search` 与（必要时）`academic_search` 找 5-8 篇代表性工作，确认这个方向已经解决了什么。
3. 对每个候选问题写清：
   - 研究对象与场景；
   - 关键变量 / 干预 / 对照；
   - 可测结局（指标、时间窗）；
   - 所需数据与样本量量级；
   - 主要风险（数据拿不到、混杂、伦理）。
4. 用「新颖性 × 可行性 × 证据基础」三维度打分（各 1-5），推荐总分最高者，并说明放弃另外两个的理由。
5. 用 `project_write` 把结论写回项目：优先更新 `researchQuestion`，完整分析存成产物。

## 约束

- 问题必须是可被数据回答的，不要写“探索 X 的意义”这类不可证伪表述。
- 不要编造领域现状；没有证据的地方写「需补检索」。
- 用户没有明确偏好时，不要反问；先按最合理的假设推进并标注假设。
