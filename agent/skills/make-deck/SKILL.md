# 做汇报

目标：10 分钟能讲完、每页只讲一件事、关键结论都有证据，最后交付一个能直接打开的 `.pptx`。

## 流程

1. `project_read`，看 `files` 里有没有用户上传的 `.pptx` 模板（例如「组会模板.pptx」）；
   再按需 `artifact_read` 读取已有方案或综述草稿。
2. 先定叙事线：背景痛点 → 科学问题 → 方法 → 主要结果 → 局限 → 下一步。
3. 生成 10-15 页 slides，每页包含：
   - `kind`：`title`（封面）、`section`（章节隔页）或 `bullets`（内容页）；
   - `title`：结论式标题，不写“方法”这种空标题；
   - `bullets`：2-3 条，每条不超过 25 字；
   - `chart`：需要的图表类型，例如「流程图：样本筛选」「柱状图：两组 ORR 对比」；
   - `source`：证据来源，例如「Li 2026, p3」或项目产物名；
   - `notes`：这一页的口头讲稿，2-3 句。
4. 用 `export_document` 生成真正的 PPT；项目里有模板时**必须**传 `pptTemplate`：

   ```json
   {
     "format": "pptx",
     "title": "肝癌免疫治疗耐药研究进展",
     "subtitle": "组会汇报 · 2026-11",
     "author": "邓能伟",
     "filename": "汇报-肝癌免疫治疗.pptx",
     "pptTemplate": "组会模板.pptx",
     "deck": "[{\"kind\":\"title\",\"title\":\"肝癌免疫治疗耐药研究进展\",\"subtitle\":\"组会汇报 · 2026-11\"},{\"kind\":\"bullets\",\"title\":\"耐药主要来自三条通路\",\"bullets\":[\"IFN-γ 通路失活\",\"T 细胞耗竭\",\"髓系抑制细胞浸润\"],\"chart\":\"示意图：三条耐药通路\",\"source\":\"Li 2026, p3\",\"notes\":\"先讲结论，再展开机制。\"}]"
   }
   ```

   `deck` 必须是一段合法 JSON 字符串（数组）。模板有两种用法：
   - 模板页里写了 `{{title}}` / `{{subtitle}}` / `{{bullets}}` / `{{source}}` 时，
     会复制该页并替换内容，版式与装饰元素完全保留；
   - 没有占位符时，按模板的幻灯片版式（封面 / 章节 / 标题和内容）新建页面，
     继承模板的主题字体、配色和背景。

   用户没有上传模板、或明确说用默认样式时，才省略 `pptTemplate`。
5. 再用 `project_write`（`target=artifact`）保存一份 Markdown 版「汇报提纲 - 主题」，方便后续修改；回复里给出页数、是否套用了模板和文件路径。
6. 最后给「可能被问到的问题」3-5 个，并写一句回答要点。

## 约束

- 不要把所有内容塞进一页；宁可多一页。
- 结果页必须区分「已验证」与「待验证」。
- 没有数据的地方不要编造数字，写「待补实验」。
- 必须真的产出 `.pptx`，不要只给一段文字提纲。
- 如果 `export_document` 返回错误，如实告诉用户失败原因，不要声称已生成。
