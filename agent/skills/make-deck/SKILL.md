# 做汇报

目标：10 分钟能讲完、每页只讲一件事、关键结论都有证据。

## 流程

1. `project_read`，必要时 `artifact_read` 读取已有方案或综述草稿。
2. 先定叙事线：背景痛点 → 科学问题 → 方法 → 主要结果 → 局限 → 下一步。
3. 生成 10-15 页提纲，每页包含：
   - 页标题（结论式，不写“方法”这种空标题）；
   - 2-3 条要点（每条不超过 25 字）；
   - 需要的图表类型（示意/流程图/柱状/森林图等）；
   - 证据来源（paperId 或项目产物）。
4. 单独给「可能被问到的问题」3-5 个，并写一句回答要点。
5. 用 `project_write` 保存为产物「汇报提纲 - 主题」（`target=artifact`），回复里给出页码结构。

## 约束

- 不要把所有内容塞进一页；宁可多一页。
- 结果页必须区分「已验证」与「待验证」。
- 没有数据的地方不要编造数字，写「待补实验」。
- 不要只给一段文字提纲就结束，必须落成项目产物。
