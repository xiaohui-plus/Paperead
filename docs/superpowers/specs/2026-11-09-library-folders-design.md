# 文献库文件夹管理 · 设计

- 日期：2026-11-09
- 状态：设计已确认，待实现
- 范围：桌面端文献库；单层文件夹

## 1. 目标

给文献库增加一套轻量、顺手的文件夹管理：

- 新建、重命名、删除文件夹。
- 把论文拖进文件夹，或在文件夹之间拖动。
- 文件夹里的论文拖到左边缘「全部文献」投放条，停留 0.7 秒移出；移出后拖拽不中断，可以继续拖到另一个文件夹。
- 空文件夹和有论文的文件夹使用不同图标与视觉状态。
- 不动现有阅读页、文献检索、研究项目的数据与交互。

## 2. 非目标

- 不做子文件夹 / 嵌套目录。
- 一篇论文只属于一个文件夹。
- 不做手机端拖拽；手机端首版不展示文件夹区，仍显示全部文献。
- 不改变 Zotero / 文献检索导入的目标：它们仍进入「全部文献」，不自动进当前文件夹。
- 不引入数据库或第三方拖拽库。

## 3. 数据模型

### 3.1 library.json

论文行新增可选字段：

```json
{
  "id": "p_...",
  "title": "...",
  "folder_id": "f_ab12cd34ef56"
}
```

- `folder_id` 缺省、为 `null` 或指向不存在的文件夹时，按「全部文献」处理。
- 现有数据不需要迁移；旧论文行自然落在全部文献。

### 3.2 folders.json

新文件 `data/folders.json`：

```json
{
  "version": 1,
  "folders": [
    {
      "id": "f_ab12cd34ef56",
      "name": "免疫治疗",
      "created_at": 1794157200
    }
  ]
}
```

- 只做单层，按 `created_at` 升序展示。
- 文件夹计数不落盘，由论文实时计算；只统计全局文献库（排除带 `project_id` 的研究项目论文）。
- 文件夹 ID 使用 `f_` + 12 位 uuid hex。

### 3.3 名称规则

- 去掉首尾空白，合并连续空白。
- 1–40 字符。
- 忽略大小写重名；重名返回 409。
- 重命名不改变文件夹在侧栏中的顺序。

### 3.4 删除语义

删除文件夹时：

1. 把该文件夹下所有论文的 `folder_id` 清空。
2. 删除文件夹记录。
3. 不删除任何论文、PDF、缩略图或解析结果。

## 4. 后端接口

沿用现有本地服务和 `LibraryStore`，所有文件夹写入与论文移动使用同一把锁。

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/folders` | 列表 + `paper_count` |
| POST | `/api/folders` | 新建，body `{ name }` |
| PATCH | `/api/folders/{id}` | 重命名，body `{ name }` |
| DELETE | `/api/folders/{id}` | 删除文件夹，论文回全部文献 |
| PATCH | `/api/papers/{id}/folder` | body `{ folder_id: string \| null }` |

`POST /api/papers/upload` 增加可选表单字段 `folder_id`：在文件夹内上传时直接放入该文件夹。

返回：

- 文件夹：`{ id, name, created_at, paper_count }`
- 删除：`{ ok: true, moved: n }`
- 论文：现有 `_public(row)` 形状，包含 `folder_id`

错误：

- 400：名称为空、超过 40 字。
- 404：文件夹或论文不存在。
- 409：文件夹重名。

## 5. 前端组件

### 5.1 LibraryFolders

新增 `web/src/components/LibraryFolders.tsx`，由 `LibraryPage` 传给 `Sidebar` 的文件夹槽位。

结构：

```text
文件夹                    +
全部文献                 23
[图标] 免疫治疗           8   ...
[图标] CRISPR 递送        0   ...
+ 新建文件夹
```

- 「全部文献」行用文献库图标，点击回到全部。
- 文件夹行显示空/非空图标、名称、数量角标。
- 新建：点 `+` 在列表顶部插入内联输入框；Enter 创建，Esc 取消，失焦时名称非空也提交。
- 重命名：双击名称进入内联输入；`…` 菜单也提供「重命名」。
- 删除：`…` 菜单 →「删除文件夹」；`window.confirm` 文案必须说明「里面 N 篇论文会回到全部文献，不会删除论文」。
- 文件夹多时列表独立滚动；拖拽靠近上下边缘时自动滚动。

### 5.2 图标与视觉

- 空文件夹：`IconFolder` 线框图标，灰色，无数量角标。
- 非空文件夹：新增 `IconFolderPapers`，文件夹内露出两页纸；蓝灰色，右侧数量角标。
- 当前选中：行背景 `--blue-soft`，图标和文字变蓝。
- 拖拽悬停：行背景变蓝、显示 inset 蓝边；图标 `translateY(-1px) scale(1.04)`；右侧出现「松开移入」。
- 拖拽中的论文卡：`opacity: .55`、`scale(.985)`，不改变布局。
- 所有过渡 150–200ms；不改变行高和 padding，避免列表抖动。

### 5.3 主区

- 全部文献：标题「文献库」，网格显示全部论文。
- 文件夹内：标题为文件夹名，旁边显示「n 篇」和「← 全部文献」；搜索、筛选、排序只作用于当前文件夹。
- 空文件夹：专用空状态「这个文件夹还是空的 / 把论文拖到左侧文件夹里」。
- 切换文件夹时网格做 160ms 淡入 + 上移 4px；用 class 触发动画，不通过 React `key` 卸载整个网格，避免拖拽中的卡片被重建。
- `prefers-reduced-motion` 下关闭动画。
- 文件夹内点「添加文章」：上传的 PDF 直接带当前 `folder_id`。
- Zotero / 文献检索导入仍进全部文献；toast 明确提示去向。

### 5.4 PaperCard

- 卡片根节点 `draggable`，`dragstart` 写入 `text/plain` 论文 id，`effectAllowed = 'move'`。
- 使用浏览器原生卡片快照作为拖拽影像；原卡半透明。
- `dragend` 清理所有拖拽状态。
- 拖拽后抑制一次 click，避免松手时误打开阅读页。

## 6. 拖拽交互

### 6.1 拖入文件夹

1. 拖起论文卡。
2. 文件夹行 `dragenter/dragover` 高亮；设置 `dropEffect = 'move'`。
3. 松手：乐观更新论文 `folder_id`、文件夹计数、当前网格；异步调用 `PATCH /api/papers/{id}/folder`。
4. 成功 toast「已移入『X』」；失败回滚并提示。

当前视图规则：

- 在全部文献里拖入文件夹：停留在全部文献，不强制跳走。
- 在文件夹 A 里拖到文件夹 B：切到 B，论文不「看起来消失」。
- 拖到当前所在文件夹：无操作，不重复请求。

### 6.2 左边缘移出（0.7 秒）

只有被拖论文当前属于某个文件夹时才出现。

1. 拖动开始，主区左边缘滑出竖向投放条（180ms，`translateX(-110%) → 8px`）。
2. 投放条包含：全部文献图标、当前文件夹名、「停留 0.7 秒移出」提示、一条进度线。
3. `dragenter/dragover` 开始计时并播放 0.7s 进度；`dragleave` 取消并复位。
4. 0.7s 完成：
   - 乐观清空论文 `folder_id`。
   - **不立即切换视图**：把被拖论文钉在当前网格里直到拖拽结束，避免源卡片 DOM 被卸载导致拖拽中断。拖拽结束后按最终归属切视图：在根目录就切全部文献，在文件夹 B 就切 B。
   - 拖拽不结束，可以继续拖进另一个文件夹。
   - 成功 toast「已移出到全部文献」。
5. 0.7s 前松手：不移出，只取消拖拽。
6. 接口失败：恢复原文件夹与当前视图，toast 报错。
7. 移出完成后投放条显示短暂 ✓，350ms 后收起；拖拽继续，仍可拖入文件夹。
8. 「全部文献」行只做导航，不作为移出投放目标；移出只认左边缘投放条，避免误触。

### 6.3 状态与性能

- 只维护一个 `dragOverFolderId`，不在每次 `dragover` 重建列表。
- 拖拽期间用 `draggingPaperId` 把源卡片钉在当前过滤结果里；即使 `folder_id` 已经变化，卡片也不卸载。
- 文件夹计数、网格过滤用派生值，不额外请求。
- 拖拽影像由浏览器负责；自绘 ghost 不在首版。
- 拖拽开始后侧栏空文件夹也可作为目标，不能因为空而禁用。

## 7. 错误与边界

- 名称重复：保留输入框，toast「已有同名文件夹」。
- 删除当前打开的文件夹：删除成功后回到全部文献。
- 论文被移动时接口失败：恢复原 `folder_id` 与视图，避免「看起来成功、刷新后回去」。
- 论文在文件夹内被删除：文件夹计数自动减少，空文件夹图标切回线框。
- 同名文件夹只在后端拒绝；前端不做抢先判断，避免多端不一致。
- 文件夹列表为空：显示「还没有文件夹」和「新建文件夹」按钮。

## 8. 测试

后端：

- `LibraryStore`：创建、重命名、重名、删除、计数、移动、移出、删除文件夹后论文回根、排除研究项目论文。
- API：CRUD、论文移动、上传带 `folder_id`、400/404/409。

前端手工验收：

- 新建空文件夹 → 线框图标、无数量角标（0 篇）。
- 拖论文入文件夹 → 数量 +1、图标切纸页、刷新后仍在。
- 文件夹 A → B → 立即切到 B。
- 文件夹内拖到左边缘，停留 0.7s → 移出；中途移开不触发，最终在根目录则切全部文献。
- 删除有论文的文件夹 → 论文回到全部文献。
- 在文件夹内上传 PDF → 进当前文件夹。
- 搜索、筛选、排序、阅读页、Zotero 导入无回归。
- `prefers-reduced-motion` 下无动画但不影响功能。

## 9. 验收标准

- 文件夹数据跟随 `data/`，重启后保留。
- 空文件夹和非空文件夹在图标、角标、文字状态上可一眼区分。
- 拖拽全程无列表跳动、无整页闪烁；0.7s 进度可见、可取消。
- 所有移动操作有明确 toast；失败可回滚。
- 不影响现有论文数据；旧 `library.json` 可直接使用。
